# Segurança

Este repositório publica apenas instaladores e metadados de versão do JARVIS IDE.

- **Não** abra issue com token, senha, chave de API ou dump de projeto AdvPL.
- Falha de segurança no cliente ou no hub: descreva o impacto sem PoC explorável em issue pública. Prefira e-mail ao maintainer da organização `jarvis-advpl`.
- Confira sempre o SHA-256 da release antes de executar o instalador. O primeiro lançamento é **unsigned**.
